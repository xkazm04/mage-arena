# Mage Arena VR

A seated, hands-first spell duel: draw sigils in the air to cast, raise your palm to absorb, flick to blink. Built in
Unreal Engine 5.8 for Meta Quest; played on the desktop first (October 2026) with hand gestures bound to keys.

- `Game/` - the Unreal project (`MageArenaVR.uproject`, C++ module `MageArenaVR`).
- `docs/` - decisions, project plan, desktop input design, art-style storyboard.
- `data/` - the pinned combat data from the Mage Arena core project.
- `tools/` - scripts the build and tests need.

Start with `docs/DECISIONS.md`, then `docs/PROJECT-PLAN.md`. Agents: read `CLAUDE.md`.
