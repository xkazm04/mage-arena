# Context sweep, 2026-10-21 — the S/M backlog

A `/perfect` sweep over 14 of the 19 mapped contexts plus one provisional context, run on **Lynx** (Windows
ARM64, no Unreal install — `docs/DECISIONS.md` 2026-10-20 "Unreal host"). The five art/audio contexts were out of
scope by the owner's ruling the same day (mechanics-first until the 31 Oct desktop-core gate).

**What this file is.** The **six L-sized directions** the owner accepted on 2026-10-21 became cards
(T43–T47, plus T48–T51) and are **not** repeated here. This file is the **S/M remainder**: everything the sweep
found that was recorded without a gate, in the shape `MOONSHOT-2026-10.md` established. It is a work list, not a
set of rulings.

**How to use it.** Each row names its evidence with a `path:line` **and a symbol**, because coordinates rot — a
wave-3 brief in a past session cited a line another wave had already moved. The full per-finding detail, including
what each scout could NOT check, lives in the loop's vault at `.perfect/Perfect/contexts/<context>.md` (gitignored
local state, one note per context). Where a row says UNVERIFIED, nobody has confirmed it and the first job is to
confirm it.

**Lane column.** `Lynx` = buildable and gateable on the Node/docs host. `Wolf` = needs the x64 Unreal host; it
compiles or renders, so it lands as a card or a card amendment, never as an unverified commit here.
