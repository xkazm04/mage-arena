# Asset ledger

The condition of the owner's ruling of 2026-10-21 on asset originality (`docs/DECISIONS.md`, "2026-10-21 - Asset originality:
AI-made assets ship with a licence ledger"; `docs/submission/RULES-CHECKLIST.md` row 6). One row per shipped asset, each with
a source line (tool, model, the log that records the call, the human edits) and a licence line (the terms that grant it and
any condition). Built 2026-10-21 from the logs and manifests under `apps/vr/art/`, which were read and not edited. No service
API was called and no key was read. An asset with no row here does not ship.

Marks: **open** = a condition is not yet met or not read; **ok** = the terms read grant the use and no condition is left.
The AI-made rows are all open: the plan in use at each paid service is not recorded in the repo, and Leonardo is not read.
