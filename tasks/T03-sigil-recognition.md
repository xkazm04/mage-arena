# T03 - Sigil recognition on fingertip paths ($Q port), clips and mouse

Status: retry 1 dispatched 2026-10-03
Max turns: 240

## Goal
Casting is drawing: the casting hand traces a circle plus an inner stroke, and the inner stroke picks one of three
spell lines (`docs/DESKTOP-INPUT.md`, plan section 4 gate D-G2, plan section 7 "gesture pipeline"). This card builds
the recognizer and its accuracy harness on the desktop: fingertip paths from hand clips (L1) and from the mouse (L2)
go through ONE recognizer and raise ONE event. Real-hand accuracy is re-measured in November; this card proves the
algorithm, the corpus and the numbers on synthetic and mouse data.

## Deliverables

### 1. Recognizer - `Game/Source/MageArenaVR/Gestures/`
- `FQPointCloudRecognizer` (plain C++, no engine dependencies beyond Core math): templates, `Classify(points) ->
  {label, score, bReject}`, a reject threshold, timing.
- `FSigilStrokeBuilder`: turns a hand-frame stream into a fingertip path: index-tip keypoint; **style A** pen-down
  while `pinch >= 0.7` (hysteresis: up below 0.5), strokes separated by pen-up; **style B** one continuous stroke
  bounded by a stillness gap (fingertip speed below a threshold for 150 ms). Projects the 3D points onto their
  best-fit plane (3x3 covariance, smallest-eigenvalue normal) and emits 2D points with stroke ids.
- A **circle check**: the gesture must contain a closed loop (start-end distance small relative to path size, or the
  first stroke's turning angle >= 300 degrees); no circle -> reject (this is what keeps a stray swipe from casting).
- `USigilRecognizerSubsystem` (`UGameInstanceSubsystem`): subscribes to the active `IHandSource`, runs the stroke
  builder and recognizer, broadcasts `OnSigilCast(FName Line, float Score, double LatencyMs)` and `OnSigilRejected`,
  logs to `LogMageArena`. The current drawing style (A/B) is a setting.
- **Mouse path (L2):** `UMouseSigilCapture` (owned by the player controller): while the left mouse button is held,
  sample the cursor every frame, project onto a plane 40 cm in front of the camera, feed the same stroke builder as
  one stroke (pen = button). The player controller binds it; keyboard quick actions keep working.

### 2. Corpus - `tools/clipgen/`
- Add a `--corpus <n> --seed <s>` mode to `generate.mjs` that writes `n` seeded drawings per sigil class per variant
  (normal/slow/sloppy) to `Game/Clips/corpus/` with distinct seeds; and **a separate template set** (`--templates`,
  different seed range) to `Game/Clips/templates/`. Templates and test drawings must never share a seed.
- Also add **noise clips**: 3 minutes total of non-sigil hand motion (ward raises, blinks, bolts, idle drift, partial
  loops that do not close) for the false-cast test.
- Keep it deterministic (same seeds, same bytes) and keep `validate.mjs` green on the new folders.
- Default corpus size: 30 per class per variant (270 test drawings). `Game/Clips/corpus/` may be git-ignored if it is
  regenerated by the test run; templates are committed.

### 3. Mouse corpus - `tools/clipgen/mousepaths.mjs`
- 2D mouse-like paths for the 3 classes (wobble, speed changes, imperfect closure), 30 per class, written as clip
  files with `"source": "mouse"` so the same loader reads them.

### 4. Tests and report - `Game/Source/MageArenaVR/Tests/SigilTests.cpp`
- `MageArena.Sigils.Templates` - templates load; one per class at least.
- `MageArena.Sigils.Accuracy` - classifies the whole corpus (clips and mouse), writes
  `Game/Saved/Reports/sigil-accuracy.json` (confusion matrix per variant and per source, top-1 accuracy, reject rate,
  per-classification time p50/p95) and **fails** below: normal >= 95 %, slow >= 95 %, sloppy >= 90 %, mouse >= 90 %.
- `MageArena.Sigils.NoFalseCasts` - over the 3 minutes of noise clips: <= 1 false cast per minute (report the number).
- `MageArena.Sigils.EndToEnd` - plays `sigil-line2.normal` through `UHandInputSubsystem::PlayQuickAction` and asserts
  exactly one `OnSigilCast` with `Line == line2`.
- Time per classification at stroke end must be <= 0.5 ms p95 on this machine (desktop proxy); report it.

## Retry 1 (orchestrator, 2026-10-03)

The first run is green but not accepted: an independent review (verified against the code by the orchestrator) shows
the tests prove "every drawing is classified as something", not "only real sigils cast". Fix all of these, keep every
existing threshold, and do not weaken a test to pass it:

1. **Rejection is inactive.** `QPointCloudRecognizer.h:34` sets `DefaultRejectDistance = 30000`, above the worst
   correct distance (23595) and reportedly above a bare circle's distance (~24147), so every reject rate is 0 %.
   Choose the threshold from data: report the distribution of correct-match distances and of impostor distances, and
   set it between them (state the margin).
2. **Add impostor drawings to the corpus and the accuracy test** (`corpus.mjs`, seeded, deterministic): bare circles
   with no inner stroke, circles with an unrelated inner mark (dot, zigzag, short hook), open arcs (< 300 degrees),
   and a stray swipe. Each must be **rejected >= 90 %** (report per kind); real sigils keep their current bars.
3. **Vacuous templates test:** `SigilTests.cpp:196-198` silently `continue`s when a template fails extraction (one did:
   `sigil-line2.sloppy.t800001011` failed the circle check). A template that cannot be extracted must fail the test;
   then fix the cause.
4. **Circle check unwinds on one-stroke drawings:** `SigilStrokeBuilder.cpp:321` uses the final net turn; after a full
   loop the inner stroke can reverse it below 300 degrees. Use the peak absolute net turn reached within the stroke
   (or detect the loop closure point), so drawing style B works.
5. **Bare-circle length is absolute:** `SigilStrokeBuilder.h:42` `BareCirclePathCm = 78` is about the circumference of
   the nominal circle, so a normal-size circle can be treated as a complete gesture and cast before the inner stroke.
   Make "waiting for the inner stroke" depend on the loop having closed, not on an absolute path length.
6. **False-cast test counts unfed seconds:** `SigilTests.cpp:~356` adds the duration of left-hand noise clips that are
   never fed to the recognizer. Feed what the casting hand would see, or count only fed seconds, and report the fed
   total (must still be >= 180 s).
7. Plane normal orientation (`SigilStrokeBuilder.cpp:112`): orient the projected 2D frame toward the head/view
   direction (seated origin +X) rather than the sign of a world component, so a drawing is never mirrored.

Report the before/after numbers for every bucket, including the new impostor buckets and the chosen threshold.
